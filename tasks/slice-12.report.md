### A5 — Offline download + conservative free-space preflight (Slice-12 §12)

`measure_offline_install_peak(...)` accounts for:

| component            | bytes |
|----------------------|-------|
| `manifest_bytes`     | manifest size                |
| `canonical_target`   | manifest size (final asset)  |
| `installer_temp`     | manifest size (download temp)|
| `validator_snapshot` | manifest size (PART-A copy)  |
| `runtime_snapshot`   | 0 (Slice 11 path; no extra)  |
| `provider_snapshot`  | 0                          |

measured = `sum(components)`,
`safety_threshold_bytes = round(measured * 1.50)`. The conservative
default is 1.50x of the manifest size. The hard floor used by
`preflight_offline_install` is `OFFLINE_INSTALL_DEFAULT_MANIFEST_BYTES
* 1.50 = 1_418_127_360 bytes` for the well-known
`1698b9979099098bf8d6e6fd7f9194134a927d428e3c2b1905a626eb8ee67d4c`
~945 MB asset.

Measurement method:

- The free-space probe uses `shutil.disk_usage(...)` (POSIX `statvfs`)
  on the install directory; failures fall back to 0 bytes which
  fails the preflight (conservative).
- The installer chain itself is
  `_download_to_temp → verify_dictionary_bytes → _atomic_rename`
  (see `app/dict_install.py:install_dictionary`). The validator
  snapshot is the canonical-asset copy used by
  `validate_candidate_dictionary` inside an unlinked temp file
  (`app/dictionary.py:_snapshot_candidate`).

Observed peak on the development host (≈ 9.99 GB free):

```
manifest_bytes              = 945_418_240
canonical_target            = 945_418_240
installer_temp              = 945_418_240
validator_snapshot          = 945_418_240
runtime_snapshot            = 0
provider_snapshot           = 0
measured                    = 3_781_672_960
safety_threshold (1.50x)    = 5_672_509_440
```

Insufficient-space behavior:

- The preflight raises `OfflineInstallRefused(code="offline_install_insufficient_disk_space", available_bytes=…, required_bytes=…)` BEFORE
  the download begins; the install dir is not touched.
- The API maps it to a structured 409 carrying the same code/value.
- Verified by
  `tests/test_slice12_settings.py::test_free_space_preflight_rejects_when_insufficient`
  (mocked `_free_bytes = 0` produces the structured error) and
  `::test_free_space_preflight_passes_with_sufficient_space`.
